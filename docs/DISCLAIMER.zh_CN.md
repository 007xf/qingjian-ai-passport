## 用量、状态与外部服务

Codex Token 仅来自本机可读记录，不是账单、配额百分比或全账户审计结果。Cursor Token 来自已登录账户的真实账单月汇总，包括输入、输出、缓存写入与缓存读取。成长只合计各来源当前周期的 Token，不把百分比换算成 Token 或金额；重复使用缓存可能在不同请求中多次计入。任一来源确认重置后，合计可能下降，角色阶段也可能改变。

完整合计及工牌阶段更新要求 Codex、Cursor 两项 Token 都完整有效。只接通一项时仍可查看单项用量，但完整成长合计会等待另一项，不把缺失来源当作零。

## 连接与耗电

自动重连会尽力恢复连接，仍受距离、无线环境、配对、macOS 权限及 Mac 电源状态影响。手动上传未收到确认时不会自动重复发送；再次上传前应检查工牌的实际结果。

可选的“熄屏继续同步”会在工牌连接时临时阻止 Mac 自动闲置休眠，离线超过 90 秒或关闭后台后释放请求。即使采用每分钟/每小时刷新及静默界面，这一设置仍可能增加耗电。它不保证手动睡眠、合盖睡眠、关机或退出登录期间保持连接。尚未测量长期续航改善，不承诺省电比例，也不承诺 AirPods 式系统接力。
