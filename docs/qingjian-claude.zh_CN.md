# 青笺 1.5.0 的 Claude Code 用量

Claude 独立显示用量。徽章成长仍为 Codex 当前周期 Token 加 Cursor 账单月 Token，没有安装 Claude 不会阻止原有合计。

## 接入与显示

1. 正常登录 Claude Code。青笺不会安装它、代为登录、直接读取钥匙串或启动模型任务。
2. 打开 **数据源接入 → Claude Code → 配置状态栏**。只有这个明确操作会保留原命令和其他状态栏选项、保留无关 hooks／设置，并保存原文件的私密备份。重复配置不会再次套一层命令；拒绝当前用户目录外或经过符号链接的设置路径。
3. 等待 Claude Code 的正常新响应。支持的 Claude.ai Pro／Max 账户会在首个响应之后提供官方 `rate_limits` 字段；不支持的套餐或独立缺失的窗口仍显示未知。**读取用量**只读已捕获的数据，不会为了刷新而发起模型响应。
4. 勾选**独立显示 Claude Code 用量页**，再**上传到名牌**。1.5.0 固件的可选页面支持 USB 与蓝牙；旧固件跳过新增命令，Mac 仍可显示读数。普通后台同步不会上传未完成的显示偏好。

观察器将原始状态栏输入字节交给原来的 shell 命令，保留其输出与退出状态。额度采集只在青笺自己的数据目录写入选定数值、时间与匿名范围哈希。App 移动时只更新已安装的解释器映射，不静默安装配置。

## 记录的 Token

从当前 `CLAUDE_CONFIG_DIR` 或默认 `.claude` 目录的 `projects/**/*.jsonl` 读取记录，包括子代理会话。每次助手 API 调用按下面口径计数：

```text
input_tokens + output_tokens + cache_creation_input_tokens + cache_read_input_tokens
```

不会再次累加 cache creation 的细分对象。API 消息与请求的别名用于对重复内容块、流式更新、分叉继承与副本去重；不同的子代理调用仍分别计数。排除合成消息、API 错误消息和用户正文。工牌显示记录日与本机历史计数，并保留原更新时间。

这是本机配置目录的记录值，可能包含历史账号；不代表账单、全账户、跨设备总量或剩余额度。不同来源版本可能漏记或低估字段，青笺不会通过费用或额度比例推算缺失 Token。不完整扫描保留上次完整观测或显示未知。缓存只持久化匿名计数与索引进度，不保存提示词、回复或明文原始 ID。

大库存达到每轮扫描预算后会在后续刷新继续，不从头反复重扫；未变化的已索引日志不会再次解析。追加、替换、改写和删除的来源在发布新完整读数前重新核对。大型用户图片记录可分块跳过；超大的助手记录或未知类型仍标为不完整，因为不能安全地假定其不含用量。第一次完整读数可能需要几轮刷新。

## 额度观测与身份

Claude Code 官方 `statusLine` 字段提供各窗口的 `used_percentage` 与 `resets_at`；不使用未公开的 OAuth usage 接口。青笺调用官方非模型命令 **`claude auth status`** 检查当前 CLI 身份范围，只对返回的邮箱／组织做哈希并丢弃原文。现代 `configDirectory` 身份字段需要 Claude Code 2.1.268 或更新版本；缺少 CLI 或身份字段时，不把缓存读数当作当前数据。

即使当前 CLI 身份匹配，也不能完全证明较早启动的会话身份，因此界面明确保留这个归属限制。不能仅因为重新绘制状态栏，就将同一会话改绑到其他已知账号，或把未知身份升级为已知身份；换账号后请开启新会话。明确换账号或退出登录时清除工牌旧额度，身份暂不可核验时只保留原时间的上次读数。

重复相同观测不会延长原额度有效期。额度最长新鲜期为三分钟，并受到窗口重置时间限制。Token 与额度各自保留时间；过期值标记为上次读数，不信任未来时间。刷新失败不会变成新的零值观测，两种 Claude 来源都不改变原有成长合计。
