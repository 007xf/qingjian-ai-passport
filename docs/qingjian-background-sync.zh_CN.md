# 后台同步与成长计数

青笺可以在关闭编辑器窗口或退出编辑器后，继续读取用量并同步已选择的工牌。
后台运行在当前登录的 Mac 用户会话中，Mac 必须保持开机并能够运行程序。
本版不能用 iPhone 替代 Mac 作为同步主机。

## 开启后台同步

1. 将青笺放在固定位置，建议放入“应用程序”，然后打开。
2. 在连接设置中选择 USB，或明确选择需要连接的蓝牙工牌。
   使用自动重连前，先完成首次蓝牙配对以及 macOS 的蓝牙权限确认。
3. 打开“后台同步”并启用，确认面板显示服务正在运行，连接目标正确。
4. 关闭或退出编辑器。已启用的后台服务会继续运行，并在此 Mac 用户下次登录时启动。

后台默认约每 60 秒增量刷新本机用量来源，可切换为每小时一次；连接心跳约每 30 秒一次。手动点击同步会立即刷新。界面静默读取后台快照，不反复显示忙碌状态。
网络或设备响应较慢时，一轮操作可能延后。编辑器显示后台服务的最新结果，
不会另开一条连接与后台争用设备。

在青笺中关闭“后台同步”即可停止服务。移动或更新 App 后，重新打开编辑器并检查
后台状态；如果原先保存的运行位置已不可用，从新的 App 位置重新启用后台。

## 蓝牙重连与上传

自动蓝牙连接使用连接设置中已经选定的工牌，不会擅自选择附近另一块设备，
也不会把蓝牙选择替换为 USB。换到另一台 Mac 后，仍需在那台 Mac 上选择设备、
完成配对并授予权限。

工牌关机、离开范围或断开时，后台会关闭失效连接，并逐步延长重试间隔，最长为
60 秒。权限问题会等待较长时间重试，供用户处理授权。Mac 从系统睡眠中唤醒后，
后台会安排重新读取状态和用量。连接恢复后继续常规同步。

设备连接只由一个后台服务操作，编辑器命令通过它按顺序执行。如果某次上传丢失
确认回复，后台不会自动重复上传；请在青笺中检查结果，需要时由你再次上传。
常规后台刷新不会重复执行工牌资料编辑或头像上传。

自定义头像上传和恢复默认头像必须使用 USB。蓝牙仍可同步文字、设置、时间、
用量和额度。Mac 保存三个阶段选择的图片，设备只缓存一张自定义阶段图片；
切换到其他自定义图片时，可能需要等待下一次 USB 更新。

## 成长值由什么组成

成长值的计算方式是：

```text
Codex 当前周周期／重置卡周期的 Token
  + Cursor 当前账户账单月的 Token
```

两个来源分别保持自己的周期。Cursor 账单月不一定从自然月的 1 日开始。
记录已使用 Codex 重置卡，只会开始新的 Codex 计数周期，不清空 Cursor 当月用量；
此操作不会实际兑换或消耗重置卡。

Codex 读取此 Mac 上可访问的会话与归档日志中的 Token 计数。统计包括输入和输出，
缓存输入已经包含在内，不会再次相加。这是本机日志计数，不保证覆盖同一账户在所有
Mac 上的使用量；历史日志也不能逐条证明每次请求属于哪个账户。

Cursor 读取已登录账户从账单月起点到观测时刻的真实用量计数。整个时间区间的聚合
包含四个独立部分：非缓存输入、输出、缓存写入、缓存读取，并用各分组之和核对总数。
这个聚合接口没有分页，不会把逐条请求明细的第一页误当成完整月用量。
分组总数只用于校验，不会再加进最终总数造成重复。

同一段上下文在多次模型调用中反复读取缓存，也会贡献 Token。因此，成长值不等于
账单金额、花费、剩余额度，也不是从额度百分比换算出来的数字。Cursor 模型和其他
模型的额度百分比仍单独显示。Cursor 接入使用客户端内部的只读用量接口，上游接口
变化时可能需要更新青笺。

已有姓名、图片和进化阈值仍由用户设置。任何一个来源确认进入新周期后，都会开始
新的成长周期标记；给旧标记首次加入 Cursor 信息，本身不会伪造一次重置。
真正的周期重置可能使合计值降低，并相应改变头像阶段。

## 上次读数与来源暂不可用

编辑器会保留以前有效的读数及原始观测时间，并在过期后标注为“上次”读数。
电量采样暂不可用、网络暂时失败或日志扫描不完整，都不会被当成零。
如果从未取得有效读数，对应值继续显示未知。

Codex 和 Cursor 的来源观测时间与有效期分别计算。Cursor 用量可使用最长五分钟的
账户隔离缓存，反复显示或发送缓存不会更新其来源时间。当前登录账户变化后，
不会继续使用另一个账户的缓存。

两项 Token 来源都新鲜、完整时，青笺才把合计值发送给工牌。某项缺失或过期时，
编辑器可以显示各来源上次已知计数及相加后的旧值，但不会把它当成新取得的完整
观测或据此推进阶段。工牌保留此前的 Token 值，其观测时间也不会被刷新。
切换到另一块工牌时，不会把前一块设备的缓存电量附到新设备上。

## 显示器熄屏不等于系统睡眠

可选的“熄屏继续同步”允许显示器熄屏，同时在后台服务运行期间阻止 Mac 因空闲
自动进入系统睡眠。这可能增加耗电。工牌离线超过 90 秒后释放保持唤醒的请求，重连后恢复；关闭后台也会立即释放。

它不保证手动“睡眠”、合盖导致的系统睡眠、关机、退出登录或 macOS 电源管理暂停
期间仍能工作。Mac 本身睡眠时，后台无法持续采集和传输；Mac 唤醒后会继续尝试。
通过三连按 OK 关闭工牌显示屏，也与 Mac 是否进入系统睡眠是两回事。

## 适用范围与验证

本版提供 Mac 同步主机、USB／蓝牙工牌连接和 Mac 编辑器，没有 iPhone App，
也没有 iPhone 后台转发。本次后台同步不引入语音或工牌内桌宠功能。

计数测试覆盖真实来源合计、缓存、过期观测、周期变化及已有阈值保留。
这些测试不能证明实际蓝牙距离、睡眠唤醒可靠性或新设备验收已通过。
具体 App／固件版本及单独列出的实机检查结果，请以对应发布说明为准。
