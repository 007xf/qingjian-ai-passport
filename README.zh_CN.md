# 青笺 · 把 AI 的使用日常带在身上

[![静态检查](https://github.com/007xf/qingjian-ai-passport/actions/workflows/static-checks.yml/badge.svg?branch=main)](https://github.com/007xf/qingjian-ai-passport/actions/workflows/static-checks.yml?query=branch%3Amain)

这两个标记显示主分支的最新检查结果，点击可查看实际运行结果与日志。

青笺是一套适用于 FoloToy AI Passport 的电子工牌固件与 Mac 编辑器。你可以在 Mac 上编辑姓名、头衔、介绍和三阶段角色图片，把本机 AI 用量与活动状态同步到随身工牌，并用 Token 成长解锁不同形态。

这是个人与 AI 协作开发的社区项目，不是 FoloToy、OpenAI、Cursor、Google 或 TYPE-MOON 的官方产品。

- 源码与问题反馈：https://github.com/007xf/qingjian-ai-passport
- Mac App、固件与校验文件：https://github.com/007xf/qingjian-ai-passport/releases/tag/v1.4.0
- AI Passport 社区玩法：[青笺 · 项目 328](https://ai-passport.folotoy.cn/plays/328/)。此前通过审核的版本已经公开；新版本的社区审核与 GitHub 发行独立进行，安装前请核对社区提供的版本号。
- 本次发行版本：1.4.0 / Mac 构建 12（社区测试版）

## 1.4.0 更新

- 后台同步独立运行：退出编辑器后仍连接已选择的工牌，支持断线自动重连，开启后随当前 Mac 用户登录启动。
- 默认每分钟静默同步，可改成每小时，也可随时手动同步；连接状态约每 30 秒检查一次，减少无变化的界面刷新。
- 成长用量合计 Codex 本周期与 Cursor 账单月的真实 Token，两者各自按原周期重置。
- 额度过期时保留上次百分比与原更新时间；自动定位更名安装的 Codex 原生命令，修复旧命令导致的读取失败。
- 修复已知电量计空白冷启动状态；已有非空电池参数不会被替换。
- 新增“角色工坊”技能与可编辑提示词，可制作自己的三阶段角色，再通过既有 USB 图片流程导入。

完整设置、统计口径与电源限制见[后台同步说明](docs/qingjian-background-sync.zh_CN.md)。

## 先看兼容范围

Mac App 需要 Apple 芯片 Mac（arm64）及 macOS 14 或更新版本，内置运行环境，不要求另外安装 Python。当前不提供 Intel Mac、Windows、iPhone 或 Android 编辑器。

固件针对 ESP32-C3、8 MB Flash、240×320 屏幕的 AI Passport，适用于已经初始化、分区布局兼容的设备。设备应保留原有身份与恢复数据。区分下文完整镜像与应用段的地址，不要执行整片擦除。空白芯片、改版硬件或不同分区布局需要单独适配。

## 它能做什么

- 电子工牌：黑色背景、透明角色、姓名、头衔、介绍、实际电量、同步时间与成长 Token。
- 角色成长：三个阶段的图片可独立替换，两次进化门槛可修改；达到最终门槛时播放短暂变身动画。
- Codex：显示主额度桶实际存在的额度窗口和重置时间，另行统计本机当前周期 Token。
- Cursor：读取已登录账户的套餐、两组已用比例、重置时间与本账单月真实 Token；活动状态独立展示。
- Gemini：保留 Gemini CLI 的本机记录与活动回调入口。原生 Gemini Mac、网页和 Antigravity 未接入。
- 智能体：按来源显示工作中、空闲、等待输入或错误；没有新记录时明确显示未知或过期。取消某个 AI 功能后，概览也隐藏对应行。
- Dino：Chromium 原版造型的离线恐龙游戏，支持跳跃、持续下蹲、暂停、重试和最高分保存。

可选功能为 Codex、Cursor、Gemini、智能体、Dino 五项。Grok Bot 已移除，独立桌宠已取消，语音暂不开发。本固件不启动 Wi-Fi 或音频。

## 安装与第一次连接

1. 从上面的 GitHub Release 下载 Mac App、固件和同版校验文件，先核对 SHA-256 与版本。不要混用不同发行版的文件。
2. 保留自己设备的完整原始备份，确认专属恢复入口可用。设备身份二维码、恢复链接和备份只保存在自己掌握的位置。
3. 如已开启青笺后台同步，先在旧 App 中关闭“后台同步”，再退出编辑器并关闭其他串口工具。**只退出编辑器不会停止后台，也不会释放设备连接。** 保持设备开机，用支持数据传输的 USB-C 线连接 Mac。
4. 按本页“固件文件与烧录地址”选择对应文件和起始地址；不要选择“清除全部数据”。社区上传的是从 `0x0` 安装的完整合并镜像，保留用户设置的既有兼容设备可选仅升级应用段。
5. 解压青笺，将完整的 `青笺.app` 放入“应用程序”后打开。此社区版本为 ad-hoc 签名，未取得 Apple 开发者签名与公证；首次打开可能被 macOS 拦截。确认下载来源与校验值后，可按 [Apple 的官方说明](https://support.apple.com/zh-cn/102445)，在尝试打开后前往“系统设置 → 隐私与安全性 → 仍要打开”。不要全局关闭系统安全检查；若提示文件已损坏或恶意内容，先停止并核对文件。
6. 在青笺的“连接设置”中选择 USB，连接设备。确认电量、时间与设备资料回读后，再编辑并点击“上传到名牌”。需要持续连接时，开启“后台同步”；蓝牙使用还需完成下文首次配对。

**已有版本升级：**先停止旧后台并退出旧编辑器，再用完整的新 `青笺.app` 替换“应用程序”中的旧版本，不要只复制可执行文件。打开新版后重新开启后台，按 macOS 正常提示恢复蓝牙或后台项目授权，并确认最近同步时间。保留原来的设置目录，已有资料、图片、功能选择与自定义门槛不因升级重置。

默认展示资料为“苍崎青子”、头衔“MISS BLUE”、介绍“如果你惹怒了我，我将会开启3技能”；三形态分别为围巾青子、红裙魔法使青子和红发青子。一阶门槛为 `77,777,777`，二阶为 `555,555,555`。首次默认选择 Codex、Cursor、智能体、Dino，Gemini 可自行开启。已有个人资料与选择应保留，不因升级重置。

示例资料不是账户数据。发行包不包含作者的登录信息、设备身份、实际 Token 或使用记录；新安装在读取到真实用量前显示未知，不预置示例截图中的计数。

## 编辑角色与日常同步

三个阶段都能独立选择图片，建议使用透明背景 PNG。角色按比例完整放入黑色背景，不拉伸身体。Mac 的“清晰预览”展示高清原图；“设备像素”用于核对设备实际素材，两者清晰度不同是预期行为。内置角色使用原生 160×160 RGB565；自定义图片受传输和内存容量限制，使用兼容的自适应压缩流程，实际精度可能较低。

所有图片写入都只支持 USB，包括更换图片和恢复内置青子。Mac 保存三个阶段的图片，工牌只缓存一张当前自定义阶段图。切换到另一张自定义阶段图时，需要再次通过 USB 同步。蓝牙连接可以继续同步文字、设置、时间、用量和状态；显示“待 USB 更新”不等于图片已经上传。

“保存草稿”只保存在本机；自动同步不会提前提交尚未上传的资料编辑或图片。选择并配对设备后开启“后台同步”，退出编辑器仍继续运行，并随当前 Mac 用户登录启动。默认约每分钟同步用量，也可在后台设置中改成每小时；需要新数据时随时点“同步”。连接状态仍约每 30 秒检查一次。

“熄屏继续同步”允许显示器关闭，同时在工牌连接时阻止自动闲置休眠，因此可能增加耗电。工牌断开超过 90 秒后会释放该请求，恢复连接后再启用。手动睡眠、合盖睡眠、关机或退出 Mac 账户仍可能中止同步；Mac 恢复运行后再尝试连接。尚未测量长时间续航改善，不能保证降低实际耗电。工牌离线后仍可展示已保存内容与游玩 Dino，冷启动时间需重新校准。

## 角色工坊：制作自己的三阶段形象

GitHub 提供[角色工坊技能](skills/qingjian-character-creator/SKILL.zh_CN.md)，名称为 `qingjian-character-creator`，以及[可编辑提示词模板](skills/qingjian-character-creator/references/character-prompts.zh_CN.md)。可以继续用青子，也可以换成其他角色或自己的原创形象；青笺中三阶段图片和进化门槛仍能独立修改。

1. 下载 [qingjian-character-creator.zip](https://github.com/007xf/qingjian-ai-passport/releases/download/v1.4.0/qingjian-character-creator.zip)，把解压得到的 `qingjian-character-creator` 文件夹放入 `~/.codex/skills/`。最终应存在 `~/.codex/skills/qingjian-character-creator/SKILL.md`；若已有自行修改的同名技能，先保留原件再替换。
2. 新开一个 Codex 会话，使用 `$qingjian-character-creator`，附上自己的参考图，说明要保留的特点和三阶段变化。例如：

   ```text
   $qingjian-character-creator
   根据我附上的参考图，制作日常、进化、最终三个阶段的全身工牌形象。
   保留已确认的脸和比例，站姿自然，背景透明，每个阶段单独输出 PNG。
   ```

3. 检查三张 PNG 的背景是否透明、四肢是否完整、角色特点是否一致。回到青笺，在对应阶段点击“选择图片”，按需修改两次进化 Token 门槛，并对照“清晰预览”和“设备像素”。
4. 使用 **USB** 连接后点击“上传到名牌”。制作图片不会自动上传；设备仍只缓存一张当前自定义形态，另一自定义阶段图可能需要下次 USB 更新。

这个技能指导有相应能力的 AI 客户端制作图片，不会让工牌或青笺编辑器自行运行图像生成。新建或修改图片需要可用的图像工具，结果仍需检查，可能需要修改多次。没有图像工具时，可以整理并导入自己已有的 PNG，或把提示词复制到现有工具使用。请确认参考图与角色的使用权限；代码许可证不包含第三方角色授权。

## 蓝牙连接

在工牌“设置 → 蓝牙配对”打开两分钟配对窗口，也可以在已连接 USB 时由青笺开启。随后在 Mac 的连接设置中搜索并明确选择自己的设备，点击连接，按系统提示输入工牌显示的六位码。必要时允许青笺使用蓝牙。

开启后台同步后，已保存的设备会自动连接；一般连接失败时逐步延长重试间隔，最长 60 秒，权限错误则等待更久以便修正。不会自行改连附近另一块工牌。USB 与蓝牙切换不重置成长周期，也不会因为重连而反复播放变身。不要用设备名称代替核对身份；周围有多块设备时，只选择自己的那一块。

手动上传若丢失确认，不会自动重发；先查看实际结果，需要时再手动上传。本版不提供 iPhone 中转或 AirPods 式系统接力。

## 接入 AI 数据

**Codex。** 先在本机正常使用并登录 Codex。青笺按应用身份自动查找原生命令，支持更名安装，读取当前可用的主额度信息，并索引本机可读的会话记录。Token 口径为输入加输出，缓存输入已经包含在输入中，不再额外相加；去除重复累计和 fork 继承部分。这不是账单，不代表全设备或全账户总量，也不能拿 Token 总数推算订阅剩余额度。不同当前账户及独立 `CODEX_HOME` 配置分开处理。

Codex 统计周期以主周额度窗口为依据。账户周额度窗口重置后开始新周期；在 Codex 实际使用重置卡后，再点击青笺“我已使用重置卡”。这个按钮只记录 Codex 新的统计起点，不清空 Cursor 本月，不购买、不兑换、不消耗真实重置卡。

**Cursor。** 先在标准 Cursor App 登录自己的账户，再在青笺点击“刷新用量”。两条进度条分别显示 Cursor 模型与其他模型的已用比例。另行读取本账单月开始至本次查询时刻的真实 Token 汇总：非缓存输入、输出、缓存写入与缓存读取相加；分组总数用于核对，不重复相加，也不把额度百分比换算成 Token。用量来自客户端当前使用的内部只读接口，并非公开稳定 API；上游修改、非标准安装位置或登录失效可能使接入暂时不可用。查询不发起模型任务、不自动刷新登录、不变更套餐或按需消费设置；每台 Mac 使用自己的登录，不复制开发者凭据。

**成长用量 = Codex 当前周期 Token + Cursor 当前账单月 Token。** Cursor 的账单月不一定从每月 1 日开始。两者各自按原周期重置；任一来源确认重置后，合计可能下降，角色阶段也可能回退。同一缓存上下文在不同模型请求中可能多次计入，成长数值不等于消费金额或剩余配额。

新的完整成长合计与工牌阶段更新要求 **Codex、Cursor 两项 Token 都可用、完整且有效**。如果这台 Mac 只安装或登录其中一个，仍可查看它的单项用量，但完整成长合计会等待另一来源，不把未接入来源默认为零。

两种来源各自保留更新时间与有效期，Cursor 缓存最长五分钟保持新鲜。刷新失败或过期时，已有有效百分比继续显示为“上次读数”，保留原始时间，不伪装成刚刚更新；从未读到过则显示未知。Token 来源过期或覆盖不完整时，不作为新的完整成长观测推进工牌阶段。选择每小时同步会有更长时间显示上次读数，需要时可以手动刷新。

需要工作状态时，打开“数据源接入”配置 Cursor 官方活动回调，然后在 Cursor 执行一个新任务，再点“重新检测”。“已配置”与“已收到活动”是两件事，单独安装青笺并不代表来源已经接通。

**Gemini。** “数据源接入”只配置 Gemini CLI 官方回调，并读取可核验的 CLI 模型记录，不连接 Gemini Mac。CLI 是否可登录并运行取决于当前账户与服务支持；开发期间的个人 CLI 验收曾被服务端拒绝，因此本项目没有宣称它已在所有账户完全连通。没有记录时保持未知，不能显示虚构的零用量。

**智能体。** 状态最长三分钟有效；过期后明确标记，不把进程存在、登录成功或历史 Token 当作正在工作。未勾选 Gemini 等来源时，对应行完全隐藏。

## 工牌按键

- 工牌页面：上、下切换已启用页面，短按 OK 进入相关设置，长按 OK 返回。
- 熄屏：快速连按三次 OK；任意功能键的完整手势只唤醒屏幕，保持原页面。
- Dino：上键跳跃，按住下键下蹲，松开站起；短 OK 开始、暂停、继续或重试，长 OK 退出。中高飞鸟可以下蹲通过，最低飞鸟需要跳跃。

熄屏关闭背光，不等同于关机或深度睡眠；需要关机请使用硬件电源键。

## 常见问题

**找不到 USB。** 确认设备开机、线材能传数据、只连接目标工牌，并关闭其他串口窗口。使用独立烧录或串口工具前，也要关闭青笺后台同步。重新插线后重新选择设备。不要通过擦除 Flash 解决连接问题。

**数值空白或过期。** 检查源 App 是否已经登录、是否存在新的本机记录，再手动刷新。过期保留上次有效百分比与时间，没有历史有效读数才显示未知，不代表零使用。

**蓝牙正在等待。** 检查目标工牌是否开机、是否在范围内、是否已授予 macOS 蓝牙权限。后台会继续重试，不必反复点击连接。

**更新后仍无电量。** 确认 App 与固件均为同版，反馈版本与脱敏后的电量诊断结果。不要写入其他设备的电池参数或擦除 Flash。

**不选 Gemini，智能体是否还显示它？** 不会。功能选择同时作用于页面和智能体概览。

**蓝牙传不了头像。** 这是当前版本的使用范围；接 USB 完成图片更新，其他数据仍可通过蓝牙同步。

**如何恢复。** 优先使用自己保留的兼容备份与本版恢复说明。出厂固件恢复入口见 [官方恢复指南](https://ai-passport.folotoy.cn/guides/restore-factory-firmware/)。专属链接含设备标识与密钥，请勿公开。恢复后可能需要重新配置资料和连接。
