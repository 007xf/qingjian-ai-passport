# 青笺 · 把 AI 的使用日常带在身上

青笺是一套适用于 FoloToy AI Passport 的电子工牌固件与 Mac 编辑器。你可以在 Mac 上编辑姓名、头衔、介绍和三阶段角色图片，把本机 AI 用量与活动状态同步到随身工牌，并用 Token 成长解锁不同形态。

这是个人与 AI 协作开发的社区项目，不是 FoloToy、OpenAI、Cursor、Google 或 TYPE-MOON 的官方产品。

- 源码与问题反馈：https://github.com/007xf/qingjian-ai-passport
- Mac App、固件与校验文件：https://github.com/007xf/qingjian-ai-passport/releases/tag/v1.3.1
- AI Passport 社区玩法：提交审核后在此补充具体链接；当前入口 https://ai-passport.folotoy.cn/plays/
- 本次发行版本：1.3.1 / Mac 构建 10（社区测试版）

## 先看兼容范围

Mac App 需要 Apple 芯片 Mac（arm64）及 macOS 14 或更新版本，内置运行环境，不要求另外安装 Python。当前不提供 Intel Mac、Windows、iPhone 或 Android 编辑器。

固件针对 ESP32-C3、8 MB Flash、240×320 屏幕的 AI Passport，适用于已经初始化、分区布局兼容的设备。设备应保留原有身份与恢复数据。区分下文完整镜像与应用段的地址，不要执行整片擦除。空白芯片、改版硬件或不同分区布局需要单独适配。

## 它能做什么

- 电子工牌：黑色背景、透明角色、姓名、头衔、介绍、实际电量、同步时间与本周期 Token。
- 角色成长：三个阶段的图片可独立替换，两次进化门槛可修改；达到最终门槛时播放短暂变身动画。
- Codex：显示主额度桶实际存在的额度窗口和重置时间，另行统计本机当前周期 Token。
- Cursor：读取已登录客户端账户的套餐、Cursor 模型和其他模型两组已用比例及重置时间；活动状态独立展示。
- Gemini：保留 Gemini CLI 的本机记录与活动回调入口。原生 Gemini Mac、网页和 Antigravity 未接入。
- 智能体：按来源显示工作中、空闲、等待输入或错误；没有新记录时明确显示未知或过期。取消某个 AI 功能后，概览也隐藏对应行。
- Dino：Chromium 原版造型的离线恐龙游戏，支持跳跃、持续下蹲、暂停、重试和最高分保存。

可选功能为 Codex、Cursor、Gemini、智能体、Dino 五项。Grok Bot 已移除，独立桌宠已取消，语音暂不开发。本固件不启动 Wi-Fi 或音频。

## 固件文件与烧录地址

- `qingjian-1.3.1-full.bin`：完整合并镜像，起始地址 **0x0**。供官方社区安装器或兼容本地刷机工具使用，包含引导程序、分区表与应用。虽然镜像不包含设备身份区和恢复区，它可能覆盖当前应用设置；刷前务必备份，不要启用整片擦除。
- `qingjian-1.3.1-app.bin`：仅应用段，起始地址 **0x10000**。只供分区布局已经兼容的设备保留配置升级；不能放到地址 0，也不能当作社区完整镜像。
- 不向他人分享自己的完整 Flash 备份、配对数据或专属恢复链接。本项目发行包仅含源码构建的通用镜像，没有作者设备转储。
- 电量充足、使用可传输数据的线材，刷写期间不要拔线。硬件或分区不符时应停止并先核对官方文档。

## 安装与第一次连接

1. 从上面的 GitHub Release 下载 Mac App、固件和同版校验文件，先核对 SHA-256 与版本。不要混用不同发行版的文件。
2. 保留自己设备的完整原始备份，确认专属恢复入口可用。设备身份二维码、恢复链接和备份只保存在自己掌握的位置。
3. 关闭正在占用设备串口的青笺或其他工具，保持设备开机，用支持数据传输的 USB-C 线连接 Mac。
4. 按本页“固件文件与烧录地址”选择对应文件和起始地址；不要选择“清除全部数据”。社区上传的是从 `0x0` 安装的完整合并镜像，保留用户设置的既有兼容设备可选仅升级应用段。
5. 解压青笺，将完整的 `青笺.app` 放入“应用程序”后打开。此社区版本为 ad-hoc 签名，未取得 Apple 开发者签名与公证；首次打开可能被 macOS 拦截。确认下载来源与校验值后，可按 [Apple 的官方说明](https://support.apple.com/zh-cn/102445)，在尝试打开后前往“系统设置 → 隐私与安全性 → 仍要打开”。不要全局关闭系统安全检查；若提示文件已损坏或恶意内容，先停止并核对文件。
6. 在青笺的“连接设置”中选择 USB，连接设备。确认电量、时间与设备资料回读后，再编辑并点击“上传到名牌”。

默认展示资料为“苍崎青子”、头衔“MISS BLUE”、介绍“如果你惹怒了我，我将会开启3技能”；三形态分别为围巾青子、红裙魔法使青子和红发青子。一阶门槛为 `77,777,777`，二阶为 `555,555,555`。首次默认选择 Codex、Cursor、智能体、Dino，Gemini 可自行开启。已有个人资料与选择应保留，不因升级重置。

示例资料不是账户数据。发行包不包含作者的登录信息、设备身份、实际 Token 或使用记录；新安装在读取到真实用量前显示未知，不预置示例截图中的计数。

## 编辑角色与日常同步

三个阶段都能独立选择图片，建议使用透明背景 PNG。角色按比例完整放入黑色背景，不拉伸身体。Mac 的“清晰预览”展示高清原图；“设备像素”用于核对设备实际素材，两者清晰度不同是预期行为。内置角色使用原生 160×160 RGB565；自定义图片受传输和内存容量限制，使用兼容的自适应压缩流程，实际精度可能较低。

所有图片写入都只支持 USB，包括更换图片和恢复内置青子。Mac 保存三个阶段的图片，工牌只缓存一张当前自定义阶段图。切换到另一张自定义阶段图时，需要再次通过 USB 同步。蓝牙连接可以继续同步文字、设置、时间、用量和状态；显示“待 USB 更新”不等于图片已经上传。

“保存草稿”只保存在本机；自动同步不会提前提交尚未上传的编辑。青笺保持打开时，约每分钟同步一次；Mac 睡眠、App 退出或连接断开会中止持续同步。设备离线后仍可展示已保存的工牌与游玩 Dino，冷启动时间需重新校准。

## 蓝牙连接

在工牌“设置 → 蓝牙配对”打开两分钟配对窗口，也可以在已连接 USB 时由青笺开启。随后在 Mac 的连接设置中搜索并明确选择自己的设备，点击连接，按系统提示输入工牌显示的六位码。必要时允许青笺使用蓝牙。

已保存的设备可以再次连接。USB 与蓝牙切换不重置成长周期，也不会因为重连而反复播放变身。不要用设备名称代替核对身份；周围有多块设备时，只选择自己的那一块。

## 接入 AI 数据

**Codex。** 先在本机正常使用并登录 Codex。青笺读取当前可用的主额度信息，并索引本机可读的会话记录。累计 Token 包括输入、输出及缓存输入，去除重复累计和 fork 继承部分；这不是账单，不代表全设备或全账户总量，也不能拿 Token 总数推算订阅剩余额度。

成长周期以主周额度窗口为依据。账户周额度窗口重置后开始新周期；在 Codex 实际使用重置卡后，再点击青笺“我已使用重置卡”。这个按钮只记录新的统计起点，不购买、不兑换、不消耗真实重置卡。

**Cursor。** 先在 Cursor App 登录自己的账户，再在青笺点击“刷新用量”。用量读取客户端当前使用的内部接口，缓存最长五分钟；它不是公开稳定 API，上游修改或登录失效可能使接入暂时不可用。两条进度条是已用比例，账户周期与 Token 成长周期分开。查询只读取已有账户状态，不发起模型任务、不自动刷新登录、不变更套餐或按需消费设置。

需要工作状态时，打开“数据源接入”配置 Cursor 官方活动回调，然后在 Cursor 执行一个新任务，再点“重新检测”。“已配置”与“已收到活动”是两件事，单独安装青笺并不代表来源已经接通。

**Gemini。** “数据源接入”只配置 Gemini CLI 官方回调，并读取可核验的 CLI 模型记录，不连接 Gemini Mac。CLI 是否可登录并运行取决于当前账户与服务支持；开发期间的个人 CLI 验收曾被服务端拒绝，因此本项目没有宣称它已在所有账户完全连通。没有记录时保持未知，不能显示虚构的零用量。

**智能体。** 状态最长三分钟有效；过期后明确标记，不把进程存在、登录成功或历史 Token 当作正在工作。未勾选 Gemini 等来源时，对应行完全隐藏。

## 工牌按键

- 工牌页面：上、下切换已启用页面，短按 OK 进入相关设置，长按 OK 返回。
- 熄屏：快速连按三次 OK；任意功能键的完整手势只唤醒屏幕，保持原页面。
- Dino：上键跳跃，按住下键下蹲，松开站起；短 OK 开始、暂停、继续或重试，长 OK 退出。中高飞鸟可以下蹲通过，最低飞鸟需要跳跃。

熄屏关闭背光，不等同于关机或深度睡眠；需要关机请使用硬件电源键。

## 常见问题

**找不到 USB。** 确认设备开机、线材能传数据、只连接目标工牌，并关闭其他串口窗口。重新插线后重新选择设备。不要通过擦除 Flash 解决连接问题。

**数值空白或过期。** 检查源 App 是否已经登录、是否存在新的本机记录，再手动刷新。未知和过期是状态提示，不代表零使用。

**不选 Gemini，智能体是否还显示它？** 不会。功能选择同时作用于页面和智能体概览。

**蓝牙传不了头像。** 这是当前版本的使用范围；接 USB 完成图片更新，其他数据仍可通过蓝牙同步。

**如何恢复。** 优先使用自己保留的兼容备份与本版恢复说明。出厂固件恢复入口见 [官方恢复指南](https://ai-passport.folotoy.cn/guides/restore-factory-firmware/)。专属链接含设备标识与密钥，请勿公开。恢复后可能需要重新配置资料和连接。
