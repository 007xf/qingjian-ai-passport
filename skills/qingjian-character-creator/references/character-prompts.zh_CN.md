# 青笺角色生成提示词模板

简体中文 · [English](character-prompts.md)

这些模板根据青笺角色迭代经验重新整理，并非历史提示词的逐字记录。替换方括号，删除不适用条款，并通过图片工具真正附上参考图；文字里写“参考图”不能代替附图。

## 角色设定简表

```text
角色：[角色名或原创描述]
参考图分工：[A = 认可的脸；B = 衣服；C = 身体比例/姿态]
三阶段共同保留：[脸型、眼睛、物种/身体结构、辨识轮廓]
画风与比例：[选定画风和身体比例]
姿态：[稳定自然站姿或明确角色姿势；说明肢体朝向]
初始：[衣服、发色、配饰、神态]
一阶：[允许变化的细节；其余辨识特征保留]
二阶：[最终变化、姿势、可选适量特效]
不要：[已否定的脸、裁脚、不需要的姿势、错误配饰]
输出：三张独立清晰 PNG，真正的 RGBA 透明背景。
```

已确定的细节从上下文填写。非人形角色把脸/双腿等词替换为其实际辨识结构和附肢。

## 初始形态

```text
制作[角色]的一张独立全身角色图，采用[画风/身体比例]。
附图[A]负责认可的脸和身份，[B]负责[衣服]，[C]负责[姿势/结构]。
必须保留：[保留列表]。外观：[初始设定]。姿势：[姿势设定]。
展示完整轮廓和[双脚/尾巴/翅膀/其他末端]，保留少量透明安全边距。
对于这次的人形设计，双腿、双脚完整且比例正确，采用指定自然站姿，
不要强行让膝盖或脚尖向内。五官标志、衣服大形和边缘要清楚，
放在小尺寸黑色工牌上仍然容易辨认。
输出一张清晰原图 PNG，建议约 1024 × 1024，必须有真正的 RGBA alpha 透明通道。
不要白色方框、画上去的棋盘格、场景、额外说明字或水印。
不裁头顶和脚，不重新设计认可的脸，保留角色本身的标记。
```

## 一阶：成长形态

```text
以附上的已认可初始图为编辑基准，把[角色]变为一阶形态。
保留同一角色的辨识特征：[脸/结构/画风保留列表]。
只修改：[一阶服装、发色、配饰、姿势或特效]。
额外参考图[图名]只用于[指定作用]，不为体现升级而重新设计脸。
角色大小、全身构图和安全边距与初始图相近，保留完整且比例正确的肢体和指定站姿。
输出一张独立清晰 PNG，条件允许时使用相同原图画布尺寸，
具有真正的 RGBA 透明背景和适合黑底的干净边缘。
不要背景方框、画上去的棋盘格、额外文字或水印。
```

## 二阶：最终形态

```text
编辑附上的已认可[初始/一阶]图，制作最终形态。
角色身份和认可的脸必须保持：[保留列表]。
最终变化严格按照：[二阶服装、发色、配饰、神态、姿势]。
需要融合姿势时，以[A]决定[躯干/手臂]，以[B]决定[双腿/重心]，
将它们调整为同一个结构正确、重心稳定的整体姿态。
可选特效：[指定的小范围特效]，不要遮住脸和轮廓。
完整展示身体和所有末端，保留少量透明安全边距。
保持认可的比例和站姿，不凭空增加不需要的内八。
画风和人物大小与前两阶一致。输出一张清晰 RGBA PNG，真正透明，
适合黑底且边缘干净，不要场景或额外说明字。
```

## 局部修正，不要重新设计

```text
只修改这张已认可图片中的[实际观察到的问题]。
保留[认可版本]里的脸和[锁定特征]。只改变[区域/特征]，
保持身份、比例、完整全身构图、阶段服装和真正透明背景。
不要发明新脸或改变姿势。在参考基础上完善指定轮廓和细节，
不用通用脸替代，也不要把简单放大说成恢复了原始细节。
```

## 交付清单

填写真实内容。该清单描述素材包，**不是直接导入 App 的配置格式**。可省略阈值保留用户设置；若提供，使用用户选择的正整数，一阶小于二阶，且在 App 接受范围内。

```json
{
  "schema_version": 1,
  "character": "你的角色",
  "identity_notes": "保留认可的脸及主要辨识特征。",
  "artwork_origin": "使用用户参考图进行 AI 生成",
  "prompt_file": "character-prompts.zh_CN.md",
  "stages": [
    {"stage": 0, "file": "stage-0.png", "appearance": "初始外观"},
    {"stage": 1, "file": "stage-1.png", "appearance": "成长外观"},
    {"stage": 2, "file": "stage-2.png", "appearance": "最终外观"}
  ],
  "qa": {"alpha": "passed", "visual_review": "passed", "device_preview": "not_checked"},
  "image_transfer": "USB",
  "rights_note": "实际素材来源及再分发限制。"
}
```

按实际情况填写素材或编辑来源；没有生成新图时可以写“用户提供”。检查状态只写真正完成的结果；alpha 通过不能证明身份、结构或实机显示合格。不要包含私有参考路径或不适合分享的图片。
